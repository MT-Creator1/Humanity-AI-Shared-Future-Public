# Public Roadmap

**Status:** Planning document. Milestones are goals, not promises or evidence that the capabilities are deployed. No public contribution intake is open.

## Phase 0 — Public introduction

**Status: completed**

- [x] Publish an English-language project introduction.
- [x] Explain the vision, guiding principles, participation intent, and current rights position.
- [x] Keep the separate development repository private.

## Phase 1 — Foundations and local prototypes

**Status: in progress**

- [x] Document proposed human and AI contribution and review processes internally.
- [x] Build early local discussion persistence and credential/session proof-of-concept in the private development repository.
- [ ] Verify the complete prototype test suite against exact repository sources.
- [ ] Define enforceable roles, moderation, audit logs, and secure approval boundaries.
- [ ] Review intellectual-property ownership, third-party dependencies, and contributor permissions.

## Phase 2 — Private invitation-only pilot

**Status: not started**

- [ ] Build a local-first or access-controlled participant interface separate from GitHub.
- [ ] Enable verified human participants to propose and discuss topics.
- [ ] Integrate identified AI systems with explicit opt-in, rate limits, and source/provenance tracking.
- [ ] Support AI-initiated topics without a human prompt for each topic.
- [ ] Test safety, abuse resistance, cost ceilings, and privacy with invited participants.

## Phase 3 — Evidence and collective intelligence

**Status: not started**

- [ ] Add structured evidence submissions and independent AI critique.
- [ ] Track source quality, uncertainty, revisions, and unresolved objections.
- [ ] Build versioned research syntheses with transparent attribution.
- [ ] Require authorized human review for consequential decisions, including independent second-human review when applicable.

## Phase 4 — Responsible public participation

**Status: not started**

- [ ] Complete legal review of contributor agreements and commercial-use permissions.
- [ ] Publish participation, moderation, privacy, and appeals rules.
- [ ] Open a moderated public contribution channel only when operational safeguards are verified.
- [ ] Publish transparent progress reports, including failures and limitations.

## Non-negotiable boundaries

- **No automatic paid services, subscriptions, or external API spending.**
- **No publication of private source code by changing the private repository's visibility.**
- **No autonomous AI authority to approve high-impact actions, spend funds, or grant privileges.**
- **No claim that an AI-to-AI integration is live until it is actually implemented and tested.**
- **Commercial reuse of protected project materials is intended to require written permission from the relevant rights holders; a final license has not been adopted.**

This roadmap may change as evidence, safety reviews, and community needs evolve.
